# MUSE Unisex Salon — Website

A modern, animated single-page marketing website for MUSE Unisex Salon —
hero, services, gallery, team, and contact sections with smooth motion and a
custom cursor.

## Features

- Single-page layout: **Hero, About, Services, Gallery, Team, Contact**
- Scroll and entrance **animations** (Framer Motion)
- **Custom cursor** and a **preloader** intro
- **Sticky call-to-action** for bookings/enquiries
- Fully responsive

## Tech stack

- React 19 + Vite
- Framer Motion (animation)
- Lucide (icons)

## Getting started

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # production build
```

## Project structure

```
src/
├─ pages/        LandingPage
├─ components/   Header, Hero, About, Services, Gallery, Team, Contact,
│                Footer, StickyCTA, CustomCursor, Preloader
└─ main.jsx
public/          logo + imagery
```
